# auto-cambio

A simulator and optimizer for a custom variant of the card game Cambio, written in Python.

## Overview

This project provides:
- **Simulator**: Play out games of the custom Cambio variant programmatically
- **Optimizer**: Find optimal strategies using simulation and search
